## Description

This project was created as part of the Semester Project 1 assignment which includes creating a style guide and high-fidelity wireframes in Figma, a GitHub Projects kanban board, and a responsive website built with HTML and CSS.

-	Semester Project 1 goal: “This assignment simulates a real-world brief that you may receive at from a web agency. The aim is to use your new knowledge of project planning, web design and development to complete the brief in the available time.”


## Built With

- Figma
- HTML
- CSS
- GitHub Projects
